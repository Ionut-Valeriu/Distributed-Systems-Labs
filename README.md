# Distributed Systems Labs

Laboratory exercises and implementations for
the Distributed Systems course (CTI - UniBuc).

## Contents

- **Lab01**: Introduction to Go
- **Lab02**: Go inter-process communication
- **Lab03**: Clocks and synchronization
- **Lab04**: Leader election and majority voting
- **Lab05**: Rendezvous
- **Lab06**: Fault tolerance (crash faults)
- **Lab07**: Byzantine faults (ByzFlood)
- **Lab08**: Shared memory systems
